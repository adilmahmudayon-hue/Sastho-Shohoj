# MediBook – Doctor Appointment System

Digitalising manual doctor appointments. **Module 1: Registration** (Patient, Doctor, Hospital/Clinic Admin).

## Run locally
```bash
npm install express better-sqlite3 bcryptjs multer
npm start
```
Open http://localhost:3000

## Stack
Node.js · Express · SQLite (better-sqlite3) · bcryptjs · multer · vanilla HTML/CSS/JS
