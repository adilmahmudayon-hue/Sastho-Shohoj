# Serial — Smart Doctor Appointment System

**Serial** is a web-based doctor appointment management system designed to simplify how patients discover doctors, explore consultation details, and request appointments through a single platform.

## Overview

Serial aims to make healthcare appointment management more organized and accessible. Patients can browse approved doctors, search using available filters, view workplace information, save favourite doctors, and request appointments.

The application is being developed using Node.js, Express.js, SQLite, and web technologies, with additional administrative and doctor-side functionality planned as development progresses.

## Repository

[GitHub — adilmahmudayon-hue/Serial](https://github.com/adilmahmudayon-hue/Serial)

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js and Express.js
- **Database:** SQLite
- **Version Control:** Git and GitHub

## Getting Started

Clone the repository:

```bash
git clone https://github.com/adilmahmudayon-hue/Serial.git
cd Serial
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm start
```

If the server starts on port 3000, open `http://localhost:3000` in your browser.

Refer to the project's setup requirements for database initialization and any required environment variables.
